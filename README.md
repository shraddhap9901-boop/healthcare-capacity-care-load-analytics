# Healthcare Capacity & Care Load Analytics

## Project Description
This project analyzes healthcare capacity and care load using Python and Streamlit. It includes data preprocessing, exploratory data analysis (EDA), interactive dashboard development, and forecasting using Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Scikit-learn

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Interactive Dashboard
- Forecasting using Linear Regression

## Dataset
Healthcare Capacity and Care Load Dataset
